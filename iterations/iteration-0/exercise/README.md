# Iteration 0：注文と在庫の引当(課題)

顧客の注文を受け付けて在庫を引き当てる，最初の仕様を書く．
要求文の例をテストにし，要求文から不変条件を読み取り，モデル検査で要求の抜けを見つけて直す．

## 学ぶこと

- 状態遷移系として仕様を書く方法(状態変数，初期状態，アクション)．
- 不変条件と，反例の読み方．
- シナリオのテスト，ランダムシミュレーション，モデル検査の違い．

## 進め方

[課題の手順](docs/iteration-0.md)に従って進める．
模範解答と解説は，[solution](../solution/README.md)にある．

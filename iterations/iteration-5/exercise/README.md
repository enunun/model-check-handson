# Iteration 5：キャンセルと出荷(課題)

キャンセルと出荷を加え，ECショップと配送システムの状態が食い違う間に起きる問題を検査する．
取消の依頼という補償処理と，食い違いがいずれ解消されることを，性質として確かめる．

## 学ぶこと

- 2つのシステムの間の結果整合性と，食い違っている間に守る安全性．
- 補償処理と，補償処理が失敗した場合の決め方．
- 状態を加えたときに，既存の性質を見直すこと．

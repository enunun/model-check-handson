# Iteration 2：決済と時間切れ(課題)

在庫の引当のあとに，決済代行サービスへの決済の依頼，結果の通知，時間切れを加える．
外部システムと時間を環境としてモデル化し，出来事の前後関係で起きる問題を見つけて直す．

## 学ぶこと

- 外部システムを，非決定的な環境として仕様に書く方法．
- 非同期の通知を，メッセージの集合として書く方法．
- 時間切れを，いつでも起きうる出来事として書く方法．

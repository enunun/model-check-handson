# 時相論理

## 一言でいうと

実行(状態の列)全体について，「いつも」「いつか」といった時間の言葉を使って性質を書く論理である．
不変条件が1つの状態について書くのに対し，時相論理は状態の並びについて書く．

## 基本の演算子

| 演算子 | 読み方 | 意味 |
| --- | --- | --- |
| `always(P)` | いつも`P` | 実行のすべての時点で`P`が成り立つ |
| `eventually(P)` | いつか`P` | 実行のある時点で`P`が成り立つ |
| `always(P implies eventually(Q))` | `P`になれば，いつか`Q` | `P`が成り立つどの時点についても，その後のある時点で`Q`が成り立つ |

最後の形は，活性を書くときに最もよく使う．
「呼び出されたら，いつか来る」「支払われたら，いつか確定か返金される」は，この形である．

## 例

信号機で考える．

- `always(light == Red or light == Yellow or light == Green)`：信号はいつも3色のどれかである．これは不変条件と同じ意味である．
- `always(light == Red implies eventually(light == Green))`：赤になったら，いつか青になる．

## 不変条件との関係

不変条件`P`は，時相論理では`always(P)`と書ける．
時相論理は，不変条件では書けない「いつか」を書ける．

## なぜ必要か

要求文の「いずれ」「必ず」「〜のままにはならない」を，検査できる形で書き表す．

## テストとの違い

テストは実行の途中の時点を確かめる．
時相論理の性質は，実行を最後まで(終わりがなければ無限に)見て確かめる．

## よくある誤解

- `eventually(P)`は，「すぐに`P`になる」ではない．いつになるかは問わない．
- `always(eventually(P))`と`eventually(always(P))`は違う．前者は「`P`が何度でも起きる」，後者は「ある時点からずっと`P`」である．

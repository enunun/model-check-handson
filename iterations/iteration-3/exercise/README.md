# Iteration 3：決済の再試行と通知の重複(課題)

決済の依頼の再試行と，同じ通知が複数回届くことを仕様に加える．
課金と返金の回数を数え，二重課金や二重返金が起きないかを検査して直す．

## 学ぶこと

- メッセージの配送保証(最大1回，最低1回)と，再試行が重複を生むこと．
- 冪等性と，冪等キーによる重複の扱い．
- 値を持つバリアント型と`match`．

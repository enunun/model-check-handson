# Iteration 1：複数の顧客が同時に注文する(課題)

注文APIの処理を「在庫の確認」と「在庫の引当」に分け，複数の顧客の手順が交互に進む場合を検査する．
テストでは再現しにくい，割り込みによる売り越しを見つけて直す．

## 学ぶこと

- 非決定的な選択で，複数の顧客の操作を表す方法．
- インターリーブと原子性．
- デッドロックと，正常な終わりの見分け方．

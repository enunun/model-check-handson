# Iteration 6：複数商品の注文(課題)

在庫を商品ごとに持ち，1件の注文に複数の商品を含められるようにする．
一部の商品だけ在庫が足りない場合の問題を見つけて直し，定数の大きさと状態の数の関係を確かめる．

## 学ぶこと

- 抽象化：調べたい問いに合わせて，仕様に書くことを選ぶ．
- 状態爆発と小スコープ仮説：小さな定数で多くの誤りが見つかること．
- `pure def`，マップのキー，`fold`．
